# Release roadmap

1. **Usable app:** reliable setup state, honest model verification, clear errors, correct game launch and feature controls.
2. **Reproducible SR and FG runtime setup:** a clean machine can provision all required permitted inputs without a developer's private checkout.
3. **Stable gameplay:** resolve SR flashes; verify FG presentation, quality, pacing, and fallback on an explicit game/hardware matrix.
4. **Distribution:** self-contained packaging, complete source notices, signed/notarized download, and fresh-machine installation tests.
5. **Experimental NR:** compare native and MLX on the same inputs and hardware, then validate a continuous game adapter behind an explicit opt-in. Do not delay SR/FG release for unfinished NR research.

Ray Reconstruction is outside the current release target. Historical experiments remain preserved in the research repository rather than mixed into the public onboarding documentation.
