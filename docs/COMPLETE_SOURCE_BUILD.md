# Building the complete SR and FG source candidate

This tree contains the native SR/FG engine source, game bridges and macOS app.
It contains no NVIDIA DLLs, model weights, game data, private captures or compiled
runtime libraries. Its five pinned binary data exceptions are model-independent
scalar calibration measurements, with their origin records and regeneration
sources. Source availability, data provisioning and distribution rights are
separate requirements.

**Publication is pending resolution of the translated-input provenance records.**
The main research repository and this candidate remain private during review.

## Compile engines without models

Use Apple silicon with an appropriate Xcode/macOS SDK and the Metal compiler.
The current engine source targets macOS 26 APIs. These commands compile source;
they do not launch games, obtain models or execute inference.

```sh
python3 scripts/build-netal-fg-engine.py --output /new/path/fg-engine
python3 scripts/build-netal-sr-reference-kernels.py --output /new/path/sr-reference
python3 scripts/build-netal-sr-boundary-kernels.py --output /new/path/sr-boundaries
python3 scripts/build-netal-sr-texture-kernels.py --output /new/path/sr-textures
```

FG produces 73 Metal libraries and arm64/x86_64/universal host archives. SR
produces eleven reference-body kernels, six boundary kernels and two texture
libraries. The source-built FG archive also links both bridges:

```sh
NEURALSTUDIO_FG_BUNDLE=/path/to/fg-engine zsh scripts/build-macos-netal-native-bridge.sh
NEURALSTUDIO_FG_BUNDLE=/path/to/fg-engine zsh scripts/build-macos-re9-metalfx-noop-bridge.sh
```

These engine directories are sufficient for linking the bridges; inference
additionally requires the local assets below. No public model download is provided.

## Assemble SR from explicit inputs

First create the supported local model package and canonical ABI templates using
[the pinned DLL setup](MODEL_SETUP.md). Both tested SR and FG DLLs report file
version 310.8.0.0, but only the recorded complete hashes identify the tested builds.

```sh
python3 scripts/build-netal-sr-assets.py \
  --model /path/to/local-sr-model --output /new/path/sr-assets
python3 scripts/assemble-netal-sr-runtime.py \
  --assets /path/to/sr-assets --model /path/to/local-sr-model \
  --scalar-contract /path/to/local-scalar-contract --output /new/path/sr-runtime
```

The scalar-contract directory must supply the four supported-size LG2/EX2
input/output tables. Their origin and numerical coverage are not established by
assembly; the helper records their full identities and leaves inference claims
false. They are **not generated by the DLL importer or distributed in this tree**.
This explicit remaining input dependency is why a complete fresh-Mac bootstrap
is still not claimed. It is not replaced by zero tables or a silent fallback.

The assembler verifies the source-build inventory, supported model hashes,
table sizes, required engine files and sanitized pointer slots. It refuses
symlinks, malformed/duplicate metadata and existing destinations, and publishes
the complete local inventory atomically. It does not copy a prepared binary runtime.

## Assemble FG from explicit inputs

```sh
python3 scripts/assemble-netal-fg-runtime.py \
  --engine /path/to/fg-engine --model /path/to/local-fg-buffers \
  --output /new/path/fg-runtime
```

The 67 supported post-evaluate buffers must be obtained from permitted local
inputs. The retained reference extraction path uses an NVIDIA D3D12 adapter;
Mac-only DLL-to-FG provisioning is not yet verified. Model integrity checks do
not obtain missing inputs or certify their origin.

## Validation of this source tree

Fresh local compilation produced all listed kernels and both bridges. A newly
assembled SR bundle reproduced the four retained 1080p RTX reference frames
exactly, with intact canaries. That result used explicitly supplied private
model/scalar/reference inputs and is limited to that sequence and mode.

The freshly compiled FG engine reproduced all 96 input/output/reference frame
records across six procedural scenes, including the 89 generated frames and
the same 20 known image-target failures. This confirms preservation of the
tested source behavior, not universal image quality or new NVIDIA parity.

The new SR assembler also passes ten synthetic error/preservation tests. CI
compiles source without models and runs synthetic policy/app/assembly checks.
It does not perform game acceptance or validate an NVIDIA capture.
